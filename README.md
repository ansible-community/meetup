# Ansible Community Meetup

This repository is the canonical home for Ansible Meetup strategy,
participant and organiser guides, technical specifications, and operational
tools. The published documentation is at
[docs.ansible.com/projects/meetup](https://docs.ansible.com/projects/meetup/en/latest/).

Choose the guide for your role:

- [Attendees](https://docs.ansible.com/projects/meetup/en/latest/attendees/index.html)
  can find events, RSVP, join the discussion, and follow up.
- [Organisers](https://docs.ansible.com/projects/meetup/en/latest/organisers/index.html)
  can learn about the role and run an event from planning through follow-up.
- [Ansible Community Team](https://docs.ansible.com/projects/meetup/en/latest/community-team/index.html)
  members can provision a city, manage organiser access, and create events.

The guides also explain how to contribute updates to this upstream community
documentation. Start at the [documentation home](https://docs.ansible.com/projects/meetup/en/latest/)
to browse all topics and reference material.
