# Glossary

- **Ansible Community Team:** The team maintaining shared Meetup infrastructure and supporting local organisers.
- **City category:** The Forum Events subcategory for one local Meetup community.
- **City organiser group:** A Forum group granting organiser access scoped to a city.
- **Event topic:** The Forum topic containing the public event details and discussion. It is the canonical event information page.
- **Forum:** The Ansible Community Forum at `forum.ansible.com`, used for event information, identity, and discussion.
- **Pretix:** The event ticketing service used for free RSVP, attendee management, and check-in.
- **RSVP:** A registration to attend an event, completed through Pretix.
- **Backlink:** The link stored on the Pretix event pointing back to its Forum event topic. It does not synchronize event data.
- **Meetup Pro migration:** The temporary process of moving existing Meetup.com members and group information into the current community services. See [legacy migration guides](legacy/meetup_pro/member-migration.md).
