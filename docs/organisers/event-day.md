# Run the event

## Before attendees arrive

1. Arrive early and check room access, seating, A/V, internet, signage, and refreshments.
2. Confirm the speaker order, timing, introductions, and any recording or photography permissions.
3. Make sure organisers know the named Code of Conduct contact and how attendees can reach them.
4. Open Pretix check-in or prepare the supported check-in app if registration uses tickets.

## Welcome attendees

- Start and finish on time; explain the agenda, facilities, and accessibility arrangements.
- Introduce the Code of Conduct contact and how to report a concern.
- Invite people to participate without requiring anyone to speak or be photographed.
- Keep talks educational and within the agreed time, leaving room for questions and connection.

## Close the event

Thank speakers, venue hosts, sponsors, volunteers, and attendees. Invite feedback and point people to the Forum topic for the recap and follow-up discussion. See the [during-event post templates](../resources/social_media_post_templates/during_event_post_templates.md).
