# Promote a Meetup

Promote the Forum event topic so people can read the details and join the discussion. The topic links to Pretix for RSVP.

## Before sharing

- Check the date, time zone, venue or online access, agenda, accessibility details, and RSVP link in the Forum topic.
- Ask speakers and sponsors before using their names, logos, or social handles.
- Make clear that attendance is free and that registration is through Pretix.

## Share the event

1. Share the Forum topic URL in local community channels, social media, relevant user groups, and calendars.
2. Use the [social media post templates](../resources/social_media_post_templates/pre_event_post_templates.md), replacing placeholders and clearly identifying the Forum event page and Pretix RSVP link.
3. Ask the Ansible Social Matrix room about including the event in Bullhorn. See the [Bullhorn category](https://forum.ansible.com/c/news/bullhorn/17).
4. Check the topic periodically and answer questions. Update the Forum post if event information changes.

Use the [event-day templates](../resources/social_media_post_templates/during_event_post_templates.md) for timely updates. External posts should point people to the Forum topic, not bypass it with a bare ticket link.
