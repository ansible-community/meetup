# Organising an Ansible Meetup

Organisers make a welcoming place for people to learn and connect. You do not need to be a software engineer; the Community Team handles the initial platform setup and creates the event listing.

Follow the event lifecycle:

1. [Understand the organiser role](role.md)
2. [Set up a Meetup on the Forum](setup-a-meetup.md)
3. [Promote the event](promote-a-meetup.md)
4. Prepare with the [event-day guide](event-day.md)
5. [Follow up after the Meetup](after-the-meetup.md)

The Forum topic is the event information page. It links to Pretix for registration, and Pretix keeps a link back to the topic. Changes to event details do not sync between services.
