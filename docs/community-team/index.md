# Ansible Community Team

The Community Team maintains the shared event environment and helps local organisers deliver Meetups. Use these procedures for operational work:

- [Provisioning the environment](provisioning.md)
- [Adding a city](adding-a-city.md)
- [Creating an event](creating-an-event.md)
- [Managing organiser access](managing-organisers.md)
- [Auditing organiser accounts](auditing-organisers.md)
- [Troubleshooting](troubleshooting.md)

The [tooling specification](../reference/tooling-specification.md) documents the automation and its configuration. The [authentication specification](../reference/pretix-discourse-auth-specification.md) describes the separate Pretix plugin.
